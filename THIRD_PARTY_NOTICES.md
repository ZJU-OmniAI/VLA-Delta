LIBERO, PyTorch3D, CuRobo, SAPIEN, MPLib, Qwen, pretrained ZR-0 weights and benchmark assets are installed/downloaded separately and retain their own terms. The root license must not be treated as a dataset or weight redistribution license.

Release decisions still required: confirm the VLA-∆ authorship/license notice and publish the base model's download location, terms and complete checkpoint artifacts. Benchmark evaluation also requires compatible fine-tuned weights and their corresponding normalization metadata. Custom Stage05/Slot/Flow annotations are user-supplied inputs for optional pretraining; their publication is not required for the base-to-LIBERO workflow. If annotations are distributed later, their permissions and source/revision must be documented. Do not publish private data paths, account configuration or credentials embedded in old experiment history; this publication workspace has been reinitialized without inherited Git history; backups and the original repository are separate.

The LeRobot dataset subset is maintained directly in the versioned root `lerobot/` directory with its compatibility changes included; users do not download or patch it separately. External LIBERO and RoboTwin repositories are downloaded by the user into `third_party/`, which is entirely ignored by Git and is not a submodule. README provides their download commands; CI pins the RoboTwin source revision used for checks. The dataset-facing `Robot` protocol is copied from the original LeRobot robot utilities to `lerobot/lerobot/configs/types.py` to avoid importing hardware drivers. The public project uses only LeRobot's dataset APIs and RoboTwin's 50 task environments and language resources. It does not maintain their unrelated policies, collection or hardware tools. Evaluation adapters live in `evaluation/`, and project-owned RoboTwin setup/check tools live in `scripts/robotwin/`; original license notices are retained outside the ignored directory.

Ignoring a directory does not remove files from older Git commits. Moving the LeRobot subset into the root directory changes the current publication layout without rewriting existing local commits.
